### New
- **Images in notes** — paste a screenshot, or copy an image file in Finder and paste it into a note. The image is kept in the note library rather than as a link to a file on disk, so moving or deleting the original does not break it, and it syncs to your other Macs through iCloud.
- **Remote images** — `![alt](https://…)` renders inline. Downloaded once and cached.
- **Image panel** — a new button in the manager window's toolbar lists every image a note holds, with thumbnails, and puts any of them back into the text. An image outlives the line that points at it, so deleting that line by accident no longer loses the picture.
- **Highlight** — `==highlighted text==` is now supported, with a Highlight entry in the right-click Format menu.

### Improved
- The right-click **Format** menu is back: bold, italic, headings and lists.
- An image's line in the source now reads `![[name|id]]` in full. The id used to be hidden, and a few ordinary edits — deleting a bracket, retyping the name, copying the line — quietly took it away and left a picture nothing could find. It is in the text now, where nothing can lose it.
- Updated the Markdown editor engine: block formulas typeset properly, tables follow the window width while you resize, and numbered lists keep their painted numbers under the caret.
- Long note and group names in the menu bar are shortened by how wide they actually draw, so the menu keeps its shape.
- Note titles no longer show `==` or `~~` markers.

### 新增
- **便签里的图片** —— 截图直接粘贴，或者在访达里拷贝图片文件再粘进便签。图片存在便签库里，不是指向磁盘上某个文件的链接，所以原文件移动或删除都不影响它，还会通过 iCloud 同步到你的其他 Mac。
- **网络图片** —— `![alt](https://…)` 直接渲染，下载一次后本地缓存。
- **图片面板** —— 管理窗口工具栏新增一个按钮，列出这条便签的所有图片（带缩略图），可以把其中任意一张放回正文。图片的寿命比指向它的那一行长，所以误删了那一行，图也不会跟着没。
- **高亮** —— 支持 `==高亮文字==`，右键「格式」菜单里也加了高亮。

### 改进
- 右键 **格式** 菜单回来了：粗体、斜体、标题、列表。
- 图片那一行的源码现在完整显示成 `![[名称|id]]`。这个 id 以前是藏起来的，而几种很普通的编辑 —— 删一个括号、重打名字、复制这一行 —— 会悄悄把它弄掉，留下一张谁也找不到的图。现在它就在正文里，丢不了。
- 升级了 Markdown 编辑器引擎：块级公式排版正确了，表格会跟着窗口宽度实时调整，有序列表的编号在光标经过时不再跳回源码里的数字。
- 菜单栏里过长的便签名和分组名，按实际绘制宽度截断，菜单不再被撑变形。
- 便签标题不再显示 `==`、`~~` 这些标记符号。
