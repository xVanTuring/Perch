### Added
- **Edit table cells in place** — click any cell of a rendered table and type into it. The table stays rendered instead of falling back to its `| a | b |` source. Tab and the arrow keys move between cells, Return breaks the line inside a cell (the row grows with it), Esc leaves. Right-clicking a cell has the full set of row and column operations plus column alignment, and the menu follows Perch's own language setting. Turn it off in Settings → Notes.
- **One-keystroke task checkboxes** — typing `- [` completes the checkbox as `- [ ] ` with the caret after the space. Also switchable in Settings → Notes.

### Improved
- Selecting text and typing an opener, a Markdown marker (`= * _ ~ $`) or a quote wraps the selection and keeps it selected — type the same one again to wrap once more (`==highlight==`, `**bold**`). Typing a closing bracket when its counterpart is already there steps over it instead of adding a second.
- **Smart quotes are off by default** — `'` and `"` stay straight in a note, which is what Markdown source wants.
- The editor no longer rubber-bands when you scroll to the very top or bottom of a note.

### Fixed
- A table no longer overlaps the text below it after the window edge has been dragged a few times.
- Typing in a table cell no longer makes the text wrap for a moment before the column widens, and the cell editor follows a wide table when you scroll it sideways.

### 新增
- **表格原地编辑** —— 点表格任意单元格直接输入,表格始终保持渲染,不再整段回落到 `| a | b |` 源码。Tab 和方向键在格子间移动,回车在格内换行(整行随之变高),Esc 退出。右键单元格有整套行列操作(插入 / 删除 / 上移下移左移右移)和列对齐,菜单跟随 Perch 的语言设置。不想要的话在「设置 → 便签」里关掉。
- **一个键搞定任务复选框** —— 输入 `- [` 就补成 `- [ ] `,光标落在空格后。同样在「设置 → 便签」里可关。

### 改进
- 选中文字后打括号、Markdown 标记(`= * _ ~ $`)或引号,会把选区包起来并保持选中 —— 再打一次同样的符号就套两层(`==高亮==`、`**加粗**`)。右边已经有对应的右括号时,再打一次会直接跳过,而不是打出第二个。
- **智能引号默认关闭** —— 便签里打 `'` `"` 保持直角引号,不再被系统换成弯引号,Markdown 源码要的就是这个。
- 滚动到便签最顶部 / 最底部时,编辑器不再橡皮筋回弹。

### 修复
- 窗口边缘反复拖宽之后,表格不再压住下面的文字。
- 在表格单元格里打字时,文字不再先折行一下再随列变宽;横向滚动宽表格时,单元格编辑器跟着一起滚,不再错位。
