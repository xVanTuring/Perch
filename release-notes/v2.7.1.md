### Fixed
- **Shortcuts can be cleared again** — on macOS 26 and later, the × button in Settings → Shortcuts did nothing, so a global shortcut could be changed but never removed. Clicking × now removes it and frees the key combination for other apps.
- **The menu bar list can close notes too** — clicking a checked note (its sticky is open) now closes the sticky, the same as clicking its × button. Unchecked notes still open or come to the front.
- Pressing ⌘S no longer plays the alert sound. Notes save automatically, so ⌘S now does nothing.

<!-- lang:zh -->
### 修复
- **快捷键可以清除了** —— 在 macOS 26 及更高版本上，设置 → 快捷键里录制框的 × 按钮点了没有反应，全局快捷键只能改、不能删。现在点 × 就能清除，这组按键也会交还给其他应用。
- **菜单栏的笔记列表也能关闭便签了** —— 点击打了勾的笔记（便签正在显示）会关闭这张便签，和点便签上的 × 效果一样。没打勾的笔记照旧是打开或带到最前。
- 按 ⌘S 不再发出系统提示音。笔记是自动保存的，⌘S 现在不做任何事。
