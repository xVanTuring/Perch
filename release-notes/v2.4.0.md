### New
- **Agent access via MCP** — Perch can now run a local MCP server so AI agents (Claude Code, etc.) can read and search your notes and groups. Turn it on in the new **Settings → Agent** tab. Off by default.
- **Write access is opt-in** — creating, editing, moving, pinning, archiving and deleting notes by an agent requires a separate "Allow agents to write" switch. Deletes go to Trash like normal, and pinning opens a real sticky window.
- **Secure by default** — the server listens on this Mac only (127.0.0.1) and requires a token, which is stored in the Keychain. The Agent tab shows ready-to-copy client configuration.

### Improved
- The Settings window is wider so all tabs fit in the toolbar without an overflow "»" menu.

### 新增
- **通过 MCP 让 AI 助手访问便签** — Perch 现在可以在本机运行 MCP 服务，让 AI 助手（如 Claude Code）读取和搜索你的便签与分组。在新增的 **设置 → Agent** 页开启，默认关闭。
- **写入权限需单独开启** — 助手创建、编辑、移动、置顶、归档或删除便签，需要另外打开「允许 Agent 写入」开关。删除操作同样进入回收站，置顶会真正打开便签窗口。
- **默认安全** — 服务只监听本机（127.0.0.1），并需要访问令牌，令牌保存在钥匙串中。Agent 设置页提供可直接复制的客户端配置。

### 改进
- 设置窗口加宽，所有设置页都能在工具栏中直接显示，不再折叠到「»」菜单里。
