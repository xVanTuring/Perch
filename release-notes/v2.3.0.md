### New
- **Stickies remember their display** — each sticky remembers which display it belongs to. Drag it to another screen and it stays there after reopening or relaunching. Unplug a display and its stickies move to the main screen; plug it back in and they return. "Move All to Display" is now remembered too.
- **Menu bar icon click actions** — choose separately what left-click and right-click on the menu bar icon do: show the menu, or open Manage All Notes.
- **Dock icon for Manage All Notes** — optionally show Perch in the Dock and the app switcher (⌘Tab) while the Manage All Notes window is open.
- **Default menu visibility for new groups** — choose whether newly created groups appear in the menu bar note list.
- **Manager remembers the last note** — Manage All Notes reopens with the note you last selected.
- **New "Menu Bar" settings tab** — menu bar options moved out of General, so the General tab is shorter.

### Improved
- The "hidden from menu bar" icon in the manager sidebar is easier to see.
- Group names and note titles in the manager sidebar stay readable when the window is inactive, turning slightly gray as other macOS apps do.

### 新增
- **便签记住所属显示器** — 每条便签会记住自己所在的显示器。拖到另一块屏幕后，重新打开或重启都会回到那块屏幕；拔掉显示器时便签暂时移到主屏幕，插回后自动归位。「全部移到显示器」也会被记住。
- **菜单栏图标点击行为** — 可分别设置左键和右键点击菜单栏图标时的动作：显示菜单，或打开「管理所有便签」。
- **管理窗口显示 Dock 图标** — 可选在「管理所有便签」窗口打开期间，让 Perch 出现在 Dock 和 ⌘Tab 应用切换器中。
- **新分组默认是否显示在菜单栏** — 可设置新建的分组是否出现在菜单栏的便签列表中。
- **管理窗口记住上次选中的笔记** — 再次打开「管理所有便签」时，自动选中上次查看的笔记。
- **新增「菜单栏」设置页** — 菜单栏相关选项从「通用」移出，「通用」页更简短。

### 改进
- 管理窗口侧边栏中「在菜单栏隐藏」的图标更清晰。
- 窗口不在前台时，侧边栏的分组名和笔记标题会适度变灰，但保持清晰可读，与 macOS 其他应用一致。
