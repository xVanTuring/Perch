### Improved
- **New notes inherit the current group** — creating a note in the manager window while another note is selected now places the new note in that note's group, instead of leaving it ungrouped.
- **Group headers** are a touch larger and bolder; a collapsed group now shows how many notes it holds.
- **New groups stay out of the menu bar by default** — a freshly created group no longer appears in the menu bar's note list until you opt it in (Manager → right-click the group). Ungrouped notes are unaffected.

### Fixed
- A visible flicker when clicking between notes in the manager sidebar — selecting a note could trigger the sidebar to rebuild itself twice in a row for no reason; now coalesced into one.

### 改进
- **新建笔记跟随当前分组** —— 在管理窗口里选中某条笔记时新建笔记，新笔记会自动归到这条笔记所在的分组，不再默认未分组。
- **分组头** 字体调大了一点，折叠后会显示这个分组下有多少条笔记。
- **新分组默认不出现在菜单栏** —— 新建的分组不再自动进菜单栏的笔记列表，需要的话在管理窗口右键该分组手动打开。未分组的笔记不受影响。

### 修复
- 修复管理窗口侧栏点选笔记时偶尔出现的闪烁 —— 点选会触发侧栏被连续重建两次，现在合并成一次。
